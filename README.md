# مينوز | MENUZ — القائمة الرقمية الذكية

> **امسح.. اطلب.. واستمتع**
>
> منصة منيو إلكتروني احترافية عبر QR Code — من تطوير **شركة سامرز للحلول الذكية**

## ما هي؟
منصة ويب (PWA) لجهة واحدة — حالياً **إندوميتو (INDOMITO)** — لإدارة قوائم الطعام والمشروبات والحلويات إلكترونياً: الزبون يمسح QR فيفتح المنيو، يضيف للسلة، ويرسل الطلب بفاتورة احترافية عبر واتساب أو SMS. صاحب المطعم يدير كل شيء من الهاتف دون إعادة طباعة.

## التقنيات (مجانية بالكامل)
- **الواجهة:** React + Vite + TypeScript + Tailwind CSS (RTL عربي، وضع ليلي، PWA)
- **قاعدة البيانات والمصادقة والتخزين:** Supabase (Postgres + Auth + Storage)
- **الاستضافة:** Vercel (نشر تلقائي من GitHub)
- **المستودع:** GitHub

## التشغيل محلياً
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # بناء الإنتاج في dist/
```

انسخ `.env.example` إلى `.env.local` واملأ مفاتيح Supabase (المفتاح `anon` آمن للنشر).

## الصفحات
| المسار | الوظيفة |
|---|---|
| `/` و `/indomito` | منيو الزبائن (عام) |
| `/admin/login` | تسجيل دخول الإدارة |
| `/admin` | لوحة التحكم (إحصائيات، أقسام، أصناف، عروض، محافظ، طلبات، بيانات الجهة، مستخدمون، QR) |

## الأدوار
- **مدير النظام (سامرز):** كل الصلاحيات بما فيها بيانات الجهة والمستخدمون.
- **مسؤول الجهة:** إدارة المنيو فقط.
- **زائر:** تصفح وطلب.
