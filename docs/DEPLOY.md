## 1) الأدوات المستخدمة (كلها مجانية)

| الأداة | الاستخدام | الخطة المجانية |
|---|---|---|
| **GitHub** | حفظ كود المشروع (المستودع `samer-zz/menuz-77`) | مجاني للأبد (مستودعات خاصة/عامة) |
| **Supabase** | قاعدة البيانات + المصادقة + تخزين الصور | مجاني: 500MB قاعدة بيانات، 1GB تخزين، 50,000 مستخدم مصادق |
| **Vercel** | استضافة الموقع (PWA) | مجاني: 100GB نقل شهرياً، نشر تلقائي من GitHub |
| **React + Vite + TypeScript** | بناء الواجهة | مفتوح المصدر |
| **Tailwind CSS** | التصميم | مفتوح المصدر |

**لماذا هذا الاختيار؟**
- Supabase بديل مجاني كامل لـ Firebase (Postgres + Auth + Storage) بدون بطاقة ائتمان.
- Vercel يعطي HTTPS مجانياً ونشراً تلقائياً عند كل تحديث على GitHub.
- الموقع ثابت (Static) + PWA: سريع جداً، يعمل بدون إنترنت جزئياً، وقابل للتثبيت كتطبيق على الجوال.

**حدود الخطة المجانية (بصراحة):**
- Supabase يتوقف مؤقتاً إذا لم يُستخدم أسبوعاً (يُستأنف بضغطة واحدة من لوحة التحكم).
- Vercel Hobby: مناسب تماماً لمنيو جهة واحدة. إذا تجاوزت 100GB شهرياً (مستحيل عملياً لمنيو مطعم) تُراجع الخطة.
- لا توجد أي رسوم شهرية ما دمت ضمن هذه الحدود.

## 3) النشر على Vercel (خطوة بخطوة)

المشروع مرتبط أصلاً بـ Vercel. إذا احتجت إعادة إنشائه:

1. ادخل إلى [vercel.com](https://vercel.com) وسجّل الدخول بحسابك.
2. **Add New → Project** ← اختر المستودع `samer-zz/menuz-77`.
3. الإعدادات:
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. **Environment Variables** (أضفها قبل النشر):
   - `VITE_SUPABASE_URL` = `https://mtwyvqnagpnotrkixzni.supabase.co`
   - `VITE_SUPABASE_ANON_KEY` = مفتاح `anon` من Supabase ← Settings ← API Keys
5. اضغط **Deploy**. سيظهر رابط الموقع خلال دقيقة.
6. بعد النشر: حدّث رابط الموقع في Supabase ← Authentication ← URL Configuration ← Site URL إلى رابط Vercel.

> ⚠️ مفتاح `anon` آمن للنشر في الواجهة (مصمم لذلك + محمي بسياسات RLS). لا تنشر أبداً مفتاح `service_role`.

## 4) قاعدة البيانات (Supabase) — ماذا يوجد؟

| الجدول | الوظيفة |
|---|---|
| `venue` | بيانات الجهة الواحدة (الاسم، الشعار، الغلاف، التواصل، التوصيل، رسالة الإيقاف) |
| `categories` | الأقسام |
| `items` | الأصناف (السعر، الشارات، التوفر، الصورة) |
| `offers` | العروض المجدولة (تختفي تلقائياً بعد انتهاء الوقت) |
| `wallets` | المحافظ الإلكترونية (الاسم، الرقم، صورة المحفظة) |
| `orders` + `order_items` | الطلبات وتفاصيلها |
| `profiles` | أدوار المستخدمين (super_admin / client_admin) |
| `analytics_events` | المسحات والمشاهدات (للإحصائيات) |

**دوال RPC آمنة** (الواجهة لا تكتب مباشرة — كل شيء عبر دوال محققة):
- `menu_snapshot()` — تجلب المنيو كاملاً في استدعاء واحد سريع.
- `place_order(payload)` — تنشئ الطلب بأسعار من قاعدة البيانات (لا يمكن التلاعب بالأسعار)، مع تحقق من رقم الجوال اليمني ومنع الطلبات المكررة.
- `track_event()` — تسجيل المسحات والمشاهدات.
- `admin_stats()` — الإحصائيات.

**الأمان:** RLS مفعّل على كل الجداول. الضيوف يقرؤون المنيو فقط. الكتابة للطاقم المصادق فقط. بيانات الجهة لمدير النظام فقط. التسجيل العام معطّل (`disable_signup = true`).

## 6) استخدام لوحة التحكم (للمطعم)

1. افتح الموقع ← مرّر للأسفل ← اضغط **دخول الإدارة** (أو اذهب إلى `/admin`).
2. سجّل الدخول بالبريد وكلمة المرور.
3. التبويبات:
   - **📊 الإحصائيات:** المسحات اليوم/الأسبوع/الشهر، الأكثر مشاهدة، أوقات الذروة، الإيرادات.
   - **🗂️ الأقسام / 🍜 الأصناف:** إضافة وتعديل وحذف. الصور تُضغط تلقائياً قبل الرفع.
   - **🔥 العروض:** حدد تاريخ ووقت البدء والانتهاء — يختفي تلقائياً.
   - **👛 المحافظ:** أضف جيب/جوالي/ون كاش مع صورة المحفظة.
   - **🧾 الطلبات:** الطلبات الواردة + تغيير الحالة (مؤكد ← قيد التحضير ← مكتمل).
   - **📷 QR Code:** حمّل واطبع رمز QR وضعه على الطاولات.
4. **الشارات:** 🔥 الأكثر طلباً، 🆕 جديد، ⏰ عرض محدود (يظهر تلقائياً عند ربط صنف بعرض نشط)، 🚫 غير متوفر.

## 7) كيف يطلب الزبون؟

1. يمسح QR ← يفتح المنيو مباشرة.
2. يتصفح الأقسام ويضيف أصنافاً إلى السلة (تظهر الكمية والسعر مباشرة).
3. يضغط **عرض السلة** ← **إتمام الطلب**: يعدّل الكميات/الملاحظات، يدخل الاسم والجوال، يختار توصيل/استلام، والدفع (نقدي أو محفظة + رقم العملية).
4. يختار الإرسال عبر **واتساب** أو **SMS** ← تُفتح الفاتورة الاحترافية جاهزة للإرسال إلى رقم المحل.
5. يُحفظ الطلب أيضاً في قاعدة البيانات ويظهر في تبويب **الطلبات** بلوحة التحكم.
